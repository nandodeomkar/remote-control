## Remote Control v1.4.0-rc1 — Phase 11 bookmarks test build (pre-UAT)

A test build so the new **browser bookmarks** feature can be tried on real phones and PCs. It has not been through its on-device checks yet, so expect rough edges — please tell me what you hit.

### Install all THREE parts, or you will see nothing new

Bookmarks is split across the phone app, the PC server, and the browser extension. **Updating only the phone shows no change at all** — with no bookmark information arriving from the PC, the app treats every tab's bookmark state as unknown and deliberately draws no star. Do all three:

1. **PC** — run `RemoteControl-Setup-v1.4.0-rc1.exe`. If Remote Control is already running, right-click the tray icon and quit it first, then continue. Your settings and paired phones are kept.
2. **Phone** — install `RemoteControl-v1.4.0-rc1.apk` over the top. Nothing is lost and you stay paired. Check Settings → About: it should read **1.4.0**.
3. **Browser — the easy one to forget.** The extension now needs a new **bookmarks** permission, so it will not do anything until you reload it. Open `chrome://extensions`, find *Remote Control — Tab Bridge*, and press its **reload** button (the circular arrow). Chrome may ask you to accept the new permission — accept it. The version shown should then read **1.2.0**. The setup exe already put the new files in place, so a reload is all that is needed.

If the phone's Bookmarks tab shows a card telling you to install the extension, the extension is not connected — go back and reload it.

### What is new — Bookmarks on the Browser screen

- The Browser screen now has a **Tabs / Bookmarks** switch at the top. Your open tabs are exactly where they were; Bookmarks is the new half.
- Browse your PC browser's bookmark folders on the phone, tap a folder to go into it, and tap a bookmark to **open it in a new tab** on the PC.
- Every open tab now carries a **star** on the right. Filled blue means that tab is bookmarked, outline means it is not. Tap to bookmark it; tap again to remove it — removing asks you to confirm first.
- **Long-press** a bookmark (or an empty folder) to delete it from your PC's bookmarks, after a confirmation. Folders that still have things in them, and the top-level folders, offer no delete at all.
- The browser buttons (back / forward / new tab / zoom) are now pinned along the bottom, so they stay reachable in both halves.
- Whichever half you were last looking at is remembered.

### Known rough edge

**Pressing and holding a tab's star also switches to that tab.** If you hold the star down instead of tapping it, the row underneath registers the press too and the PC switches to that tab. The star still bookmarks exactly once, so nothing is lost or doubled — it just also changes tabs. A quick tap avoids it. This falls out of the way tab rows respond the instant you touch them, and fixing it properly is its own separate change.

### Worth poking at

This is a pre-release test build — the feature's on-device walkthrough has not been run yet. Most useful things to try:

- Does the extension reload cleanly and accept the bookmarks permission?
- Do your real bookmark folders show up on the phone, and do they match what the PC has?
- Does tapping a bookmark open the right page?
- Does the star match reality after you bookmark or unbookmark something from the PC itself?

### What you need

- **`RemoteControl-Setup-v1.4.0-rc1.exe`** — for the **PC**
- **`RemoteControl-v1.4.0-rc1.apk`** — for the **Android phone**
- `RemoteControl-Extension-v1.4.0-rc1.zip` — only if you run the bare server exe instead of the installer; the setup exe already installs the extension for you.

### First time here?

Full install instructions — the SmartScreen warning, the firewall prompt, and pairing by QR code — are in the [v1.3.0 release notes](../../releases/tag/v1.3.0). None of those steps have changed.
