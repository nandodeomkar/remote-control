## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PC-supplied bookmark titles → rendered widgets | Untrusted display text from the PC crosses into the phone's UI here |
| user long-press → onDelete callback | Destructive intent originates here and must not be reachable by accident |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-13 | Tampering | title rendering | mitigate | Titles are rendered as plain `Text` with `maxLines: 1` and `TextOverflow.ellipsis` — never parsed, never interpolated into a command, never used as an identity.
