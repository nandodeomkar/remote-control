<objective>
Build the client state layer for bookmarks: park the pushed `BookmarksSnapshot` on
`ConnectionService`, add a `BookmarksNotifier` that owns local folder navigation over the flat node
list, and give `TabsNotifier` the D-12 optimistic star overlay.

Purpose: D-06 says the phone navigates locally, so the drill-down state has no wire representation
at all — it must live in the notifier so a pushed snapshot cannot reset it (that is D-04's "several
bookmarks in a row without losing the current folder position"). D-12's optimistic flip is the
project's first optimistic-then-reconcile surface; every other screen renders the authoritative
snapshot only, so the reconcile rule has to be exact and unit-proven.

No widgets in this plan. Every behaviour here is provable in a bare `ProviderContainer`.

Output: `BookmarksSnapshot`, `ConnectionService.bookmarksSnapshot`, `bookmarks_store.dart`,
`TabsViewState.optimisticStars` / `bookmarkedFor`, `TabsNotifier.star` / `unstar`, and two test
files.
</objective>
