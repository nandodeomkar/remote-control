<objective>
Push bookmark state to authed phones: add the `ServerDeps.bookmarks` watch receiver, thread it
through the accept loop into `run_session`, and add the `AuthState::Authed`-gated select! arm that
encodes a `bm.changed` frame — a byte-discipline clone of the shipped `tabs.changed` arm.

Purpose: without this, the phone can only ever pull `bm.list` once and would render a bookmark
tree that never updates, and would keep rendering it after the browser closed. The auth gate is
the T-06-01 privacy backstop: omitting it leaks the owner's bookmark titles to an unauthenticated
peer.

Explicitly NOT built: an after-auth `bm.changed` snapshot. `tabs.changed` deliberately has none —
the client pulls on open — and D-03 extends that to a pull on first Bookmarks-segment display.

Output: `ServerDeps.bookmarks`, the listener clone, the `run_session` parameter, the gated push
arm, `bm_changed_frame`, and an integration test proving pre-auth silence then a single push.
</objective>
