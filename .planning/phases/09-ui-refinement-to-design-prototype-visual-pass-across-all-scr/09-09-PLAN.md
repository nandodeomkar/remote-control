  `font-weight: normal` — no per-glyph variation overrides. One global setting

Package facts (verified on pub.dev 2026-07-16):
- `material_symbols_icons` v4.2951.0; exposes `Symbols.<name>` (outlined),
  `Symbols.<name>_rounded`, `Symbols.<name>_sharp` as const IconData.
- Const usage tree-shakes normally in release builds. ONLY the runtime `get()`
  lookup breaks tree-shaking — do NOT use `get()`, `SymbolsGet`, or any
  string-to-icon lookup anywhere.
- The bundled variable fonts default to `FILL 0, wght 400, GRAD 0, opsz 48`.
  The opsz-48 default is thinner than the prototype's opsz 24 — hence the
  explicit IconThemeData pin in Task 1. Do NOT use
  `MaterialSymbolsBase.setRoundedVariationDefaults()` / `VariedIcon.varied()` —
  the IconTheme route is plain Flutter, needs no wrapper widget, and keeps every
  call site a normal `Icon(...)`.
