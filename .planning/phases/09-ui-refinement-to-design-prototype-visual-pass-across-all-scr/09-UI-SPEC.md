## Typography

Four roles, two weights. All sizes and weights are lifted from the prototype.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Display | 28px | 600 | 1.2 | Presenter elapsed timer only (`font-feature: tnum`) |
| Heading | 16px | 600 | 1.2 | App-bar title, tile label, section headers ("Favorites", "Open windows", "Recent"), primary button labels, dialog title, list primary text |
| Body | 14px | 400 | 1.5 | Banner text, list-item titles, dialog body, history rows (1.4), settings row labels, nav-cap labels |
| Label | 12px | 500–600 | 1.3 | Status chip word (600), latency readout (400), hints, meta lines, tab labels, info caption, countdown |

**Weights:** exactly two — `FontWeight.w400` (regular) and `FontWeight.w600` (semibold).
**Exception:** `FontWeight.w500` appears on the phone status-bar clock (device chrome, not app) and MAY be used on the "Retry now" / "Add / switch PC" affordances where the existing code already uses w500 — keep as-is, do not churn.

**Tabular figures:** apply `FontFeature.tabularFigures()` to every numeric readout — latency `· {n} ms`, volume `{n}%`, presenter timer `mm:ss`, power countdown `{n}s`. The prototype sets `font-feature-settings:'tnum'` on all four.

## Component State Contract

The prototype is state-machine driven. These state→style mappings are the contract (extracted from `support.js` `renderVals`). "Offline" = chip status `disconnected`.

**Tool button / key / list row (rest → pressed → offline):**
| State | Fill | Border | Text/Icon |
|-------|------|--------|-----------|
| Rest (online) | `#16181D` | `#2A2D34` | `#E6E8EB` |
| Pressed flash (online, 140ms) | `#16181D` | `#4C8DFF` | `#4C8DFF` |
| Offline / disabled | `#16181D` | `#2A2D34` | `#6B7280` |

**Modifier chip (KEY-03):** rest = `#16181D` / border `#2A2D34` / text `#E6E8EB`; **armed** = fill `#16181D` / border `#4C8DFF` / text `#4C8DFF`; **locked** = fill `#4C8DFF` / border `#4C8DFF` / text `#0E0F12` + trailing `Icons.lock` (15px). Transition `background 150ms, border-color 150ms`.

**Toggle switch (48×28, radius 999):** off = track `#2A2D34`, knob `#E6E8EB` at left `3px`; on = track `#4C8DFF`, knob `#0E0F12` at left `23px`. Transition `left 200ms`, `background 200ms`.

**Slider (volume / sensitivity):** track 4px `#2A2D34` radius 999; fill `#4C8DFF` (online) / `#6B7280` (offline); thumb 16px circle same color as fill. Volume shows `0%` fill + `#0E0F12` mute-icon when muted.

**Power slide track (64px, radius 16):** track fill tint `rgba(76,141,255,0.2)` (safe) / `rgba(255,107,107,0.2)` (destructive); thumb 56px square radius 12 in `#4C8DFF` (safe) / `#FF6B6B` (destructive) with `chevron_right`; label `#6B7280` fading out as the thumb advances; snap-back transition `left 200ms ease, width 200ms ease` when released below 0.9.

**Hub tile:** fill `#16181D`, border `#2A2D34`, radius 16, aspect ~1.4:1, centered icon 32px `#6B7280` + 4px gap + label 16/600. Online = `#E6E8EB` label + InkWell ripple (navigation, no accent flash). Offline (D-08) = `#6B7280` label, `onTap` null, no ripple, layout unchanged. Hover border `#3a3e47` is desktop-only — ignore on mobile.

## Dot-Grid Trackpad Texture (the headline delta)

Currently `trackpad_core.dart` renders a flat `color: kBg` surface (line ~240). Add the prototype's dot texture to **both** the full Trackpad surface and the floating-window surface.

- **Base:** `#0E0F12` (`kBg`)
- **Dot:** `radial-gradient(circle at center, rgba(255,255,255,0.045) 1.2px, transparent 1.2px)` — i.e. a `1.2px`-radius dot at `rgba(255,255,255,0.045)` (≈ white @ 4.5% opacity).
- **Tile size:** `24px × 24px` on the full Trackpad screen; `22px × 22px` in the floating window.
- Implement as a repeating painter/decoration behind the gesture layer; it MUST NOT intercept pointer events (`pointer-events:none` equivalent — keep it purely decorative under the `Listener`).

**Explicitly EXCLUDED (locked user decision, STATE.md 2026-07-16):**
- NO fake cursor dot (the prototype's glowing blue `mainCurX/Y` dot) — do not implement.
- NO tap ripple (`rippop` animation) — do not implement.
The hint text ("Drag to move the cursor" / "Not connected", `#4a505c`, centered) and the drag-lock pill stay.
