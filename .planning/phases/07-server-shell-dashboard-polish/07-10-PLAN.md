## Phase Goal (slice)

**As the** owner, **I want to** every screen to share one theme, honor the haptics switch, and keep the screen awake without leaks, **so that** the whole app is consistent and my toggle actually works (UI-02). This plan migrates the existing screens onto the 07-09 primitives.

<objective>
Migrate the whole existing UI onto the 07-09 primitives: delete the copy-pasted `const Color _bg/_surface/...` blocks in every screen and import from `theme/tokens.dart` (D-12); route the ~15 `HapticFeedback.*Impact()` call sites through `hapticTick()`/`hapticTickMedium()` (D-13); route Trackpad and Presenter keep-awake through the ref-counted helper (D-14); and switch main.dart's inline ThemeData to `buildAppTheme()`. A grep-guard test locks the single-source palette. This is a wide, mechanical migration touching many screens but each edit is small.

Purpose: the consolidation is the actual UI-02 deliverable; without migrating call sites the haptics toggle and the keep-awake ref-count have no effect.
Output: all screens on the token source, all haptics gated, keep-awake ref-counted, buildAppTheme() live, grep-guard test green.
</objective>
