<objective>
Create `lib/trackpad/floating_trackpad_window.dart` — the expanded-state floating trackpad card (decision D8-03). It is a fixed ~78%w × ~38%h card with a drag-by-header header bar, the shared `TrackpadCore` gesture surface (from 08-02), and a reused `MouseButtonsBar`. Because it mounts the same `TrackpadCore`, its cursor input is behavior-identical to the full screen (SC2). Window drag is header-only and clamps fully on-screen; position persists via the 08-01 window notifier. No new REQ-IDs are mapped to Phase 8; this preserves the shipped PAD-01..05 gesture surface inside the window.

Purpose: The header `GestureDetector` and the core `Listener` are spatially disjoint SIBLINGS in the window Column (RESEARCH Pitfall 2) so "gesture-surface touches are always mouse input" holds with no arena contention. This plan also lands the A2 short-device layout guard as an automated no-overflow test.

Output: `lib/trackpad/floating_trackpad_window.dart` + `test/floating_trackpad_window_test.dart`.
</objective>
