<objective>
Create `lib/widgets/bubble_scaffold.dart` — the per-screen overlay scaffold that replaces `QuickBarScaffold` (decision D8-05). It composes the tool body + the verbatim UIPI banner slot + an expand-gated bubble/window subtree in one `Stack`, owns the expand `ValueNotifier<bool>` + 200ms scale/fade `AnimationController` + `PopScope` collapse-first back handling. This is decisions D8-01 (never both visible), D8-05 (scaffold swap, `showBubble`), D8-07 (localized-rebuild expand), and D8-08 (nav + back). No new REQ-IDs are mapped to Phase 8; this backs UI-01 (the quick-bar → bubble replacement) and rides PAD-05 (the window's instant cursor via the shared core).

Purpose: Approach A per the spec — Stack children, NOT `OverlayEntry` (which would fight `PopScope` + the per-screen-ephemeral lifecycle). The tool body is a `Positioned.fill` sibling OUTSIDE the `ValueListenableBuilder`, so expand/collapse never rebuilds the tool screen (Pitfall 3/6). A1 is resolved: use `onPopInvokedWithResult` (confirmed non-deprecated on the pinned Flutter 3.44.5 — the `onPopInvoked` variant is `@Deprecated`).

Output: `lib/widgets/bubble_scaffold.dart` + `test/bubble_scaffold_test.dart` (supersedes the deleted `quick_bar_test.dart`, which 08-06 removes).
</objective>
