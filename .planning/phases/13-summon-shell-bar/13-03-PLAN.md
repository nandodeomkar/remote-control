  <action>
    Add a second `AnimationController` to the shell `State`: `_swap`, with
    `duration: kSummonSwapDuration` and an initial `value: 1`. The rendered surface height becomes
    a lerp between a `_fromHeight` and a `_toHeight` driven by `Curves.easeOut` over `_swap.value`,
    so the surface resizes to the other surface's height while staying up.

    The three transitions, exactly:

    - **Raise** — `_toHeight = summonSurfaceHeight(kind, available)`, `_fromHeight = _toHeight`,
      `_swap.value = 1`, then forward the raise controller. Nothing lerps.
    - **Lower** — reverse the raise controller from its live value. No queue, no input lockout;
      this is the framework default and the owner left it to discretion. A reverse from a
      half-raised surface settles in roughly half the lower duration because the controller scales
      by the remaining distance.
    - **Swap** — `_fromHeight` = the current rendered height, `_toHeight =
      summonSurfaceHeight(otherKind, available)`, then `_swap.forward(from: 0)`. The raise
      controller is **untouched and stays at 1**. This is one motion, not a 150ms lower followed
      by a 200ms raise, and there must be no lower-then-raise anywhere in the code path.

    Wire the dismiss seam. `SummonShellController.onSurfaceDismissed` must be invoked with the
    **outgoing** surface kind from **both** the lower path and the swap path, through exactly one
    call expression each, and its doc comment must state that in one sentence. Phase 14 wires the
    trackpad's drag-lock flush and keep-awake release to this seam; Phase 15 wires the keyboard's
    modifier release to it. If this plan ships two unrelated call sites, Phase 15 will wire to one
    of them and every swap will leave a modifier physically held on the PC with no chip on screen
    to release it. Add a test-visible hook so a widget test can observe the seam firing on both
    edges without needing a surface to exist.

    Curves: `Curves.easeOut` in, `Curves.easeIn` out as the raise controller's reverse curve, and
    `Curves.easeOut` on the swap height lerp. No new curve type — enter decelerates, exit
    accelerates, and that is already the house vocabulary. Do not add a reduced-motion branch: a
    200/150ms translate with no parallax, scale, blur or opacity is already inside every
    reduced-motion guideline, and a conditional path would double the timing surface MOT-01 has to
    pin. Record that as a comment so it is visibly a decision.

    Do not introduce any new animation primitive — no shimmer, skeleton, scrim fade, bounce,
    spring, scale, rotation, or cross-fade between the two surfaces' content.
