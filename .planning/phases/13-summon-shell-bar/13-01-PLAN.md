<objective>
Prove the host shape end to end, then wire it into the app.

The back-dismiss mechanism this entire phase rests on is **unproven in this tree**:
`PopScope` registers with the enclosing `ModalRoute`, and above the Navigator there
is no route — so a shell-level `PopScope` is a **silent no-op**: no error, no
warning, no log. This plan is the tracer. It builds the real host (`SummonShell` at
`MaterialApp.builder`), the real per-route `SummonBackGuard`, and the real ownership
model (a monotonic `int` guard-id stack, D-13-19), and drives a system back through
all of them.

Purpose: if the guard does not intercept, the host shape changes, and this is the
cheapest place in the milestone to find that out. Everything else in Phase 13 depends
on this plan.
Output: `TEST-MIGRATION.md`; `lib/shell/{summon_scope,summon_shell,summon_back_guard}.dart`;
the `main.dart` insertion; `test/shell/summon_back_guard_spike_test.dart`; and a
recorded before/after full-suite result for the BAR-05 reservation.
</objective>
