<objective>
Create `lib/widgets/trackpad_bubble.dart` — the minimized draggable bubble that replaces the reserved-slot quick-bar affordance (decision D8-02). It is a 56dp circle carrying `Icons.touch_app` on `kAccent`, tappable to expand, draggable anywhere, and on release it animates (200ms ease-out) to the nearest left/right edge with an 8px inset and persists `(edge, yFraction)` to the bubble position notifier from 08-01. No new REQ-IDs are mapped to Phase 8; this backs the UI-01 quick-bar → bubble replacement.

Purpose: A leaf, callback-injection widget (service-agnostic) so its widget test needs no live service or Navigator — mirroring the `MouseButtonsBar` house shape. Off the hot path, so drag animation and edge-snap use `GestureDetector` + `AnimationController` (NOT `Draggable`/`DragTarget` — wrong semantics).

Output: `lib/widgets/trackpad_bubble.dart` + `test/trackpad_bubble_test.dart`.
</objective>
