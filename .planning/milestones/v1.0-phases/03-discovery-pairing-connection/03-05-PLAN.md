<objective>
The phase's namesake: ConnectionService, the reconnect driver that makes connectivity a solved problem. It executes the 03-02 FSM's effects with real IO — dialing through the gate-proven `connectNoDelay` (kept verbatim), running the existing HandshakeDriver per attempt, persisting tokens through the 03-03 DeviceStore, short-circuiting backoff on 03-04 beacon sightings, enforcing the RFC1918 private-range dial guard (the code half of D-10), and extending the LatencyProbe with idle-ping liveness so the header (03-07) has a latency + dead-connection source (D-08, CONN-06).

The single-stream-listener routing and the authed gating move here from trackpad_screen.dart conceptually — but this plan does NOT touch trackpad_screen.dart (03-07 slims it); the service exposes the API the screens will consume.

PIN retry model (verified against session.rs): the server leaves the session open after authFail, but the client HandshakeFsm is terminal on failure — so every PIN attempt is a FRESH dial (connect → challenge → needPin), driven by the pairing sheet calling connectTo again. This keeps HandshakeFsm unchanged (CONTEXT lock: wrap, don't rewrite).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phone → LAN ws:// | Cleartext WebSocket dials (post-XML-swap, code guard here) |
| Server frames → client FSMs | Untrusted wire input routed by the single listener |
| Beacon stream → dial targeting | Unauthenticated input chooses WHERE the client dials |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16 | Information Disclosure | dial targets | mitigate | isPrivateLanAddress refuses non-RFC1918/link-local dials in code — the enforceable half of D-10's "LAN ranges only" (Android XML cannot express it); unit truth table |
| T-03-17 | Spoofing | rogue endpoint reached via spoofed beacon | mitigate | Client sends only hello + authProof(HMAC over the SERVER's nonce) — a rogue server harvests an HMAC over its own nonce, useless elsewhere (SPEC §4); token itself never transmitted (test-asserted on the sink log) |
| T-03-18 | Denial of Service | retry engine vs server lockout | mitigate | Auth-stop wired end-to-end: revoked test asserts exactly one dial; backoff caps at 10s with jitter (thundering-herd hygiene) |

| T-03-20 | Information Disclosure | token in memory/logs | mitigate | Token flows connect-time only: store → HandshakeDriver ctor; never stored on ConnectionService fields, never in changes events, never logged (secrets discipline carried from handshake_fsm) |
