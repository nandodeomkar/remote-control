## Phase Goal (slice)

**As the** owner, **I want to** toggle "start with Windows" and be warned honestly when my firewall would block the phone, **so that** the server is a set-and-forget daily driver instead of silently unreachable (SRV-02 + SRV-04). This plan builds the OS-integration primitives those features consume; wiring into startup/tray lands in 07-06/07-08.

<objective>
Build three self-contained server-windows OS-integration modules — `autostart.rs` (auto-launch HKCU wrapper), `firewall.rs` (read-only INetFwPolicy2 inbound check + bind-error classifier), and a `notify.rs` extension (firewall-warning toast) — each independently testable and free of `main.rs`. The composition root (07-06) and the settings window (07-08) call into these; this plan owns none of the wiring, only the primitives.

Purpose: isolating the Win32/registry/COM primitives from the composition root keeps main.rs churn minimal and lets these be `#[ignore]`-tested against real OS state.
Output: `autostart::{enable,disable,is_enabled}`, `firewall::{inbound_allowed, classify_bind_error}`, `notify::notify_firewall_warning`.
</objective>
