# Phase 7 — UI Design Contract

> Visual and interaction contract for the **Flutter Android client** half of Phase 7 (UI-01, UI-02).
> This is a **consolidation + extension** contract over the design system already shipped through Phase 6 — not a greenfield system. It documents the existing tokens as the single source of truth and specifies the new/changed surfaces: the uniform 2×4 dashboard, offline-disabled tile state, the persistent Trackpad quick-bar, the new Keyboard tile/screen, the App Settings screen, and the UIPI transient banner (SRV-05 client surface).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Out of contract scope (do NOT spec here):** the native Windows tray icon, egui settings window, firewall/UIPI *server* detection — those are Windows chrome (SRV-01..05 server half). Also out: user-selectable accent presets and the live "peek" trackpad overlay (both deferred).

**Token source of truth (D-12):** `app/remote_control/lib/theme/tokens.dart` — a single file exporting the palette consts below + a `buildAppTheme()`. Every screen must import from here; the copy-pasted `const Color _bg = ...` blocks in each screen file are deleted and replaced with imports. A grep-guard test (no per-file palette literal regressions) is a UI-02 acceptance check.

## Spacing Scale

Declared values (multiples of 4 — 8-point aligned). Matches the tokens already used in `hub_screen.dart` (`md` edge padding, `xl` top padding, `xs` icon gap).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap (tile), inline micro-spacing |
| sm | 8px | Compact element spacing, chip padding |
| md | 16px | Default: grid edge padding, inter-tile gaps, list row padding, app-bar action inset |
| lg | 24px | Section padding inside Settings screen groups |
| xl | 32px | Grid top padding, major section breaks |
| 2xl | 48px | Reserved (empty-state vertical rhythm) |
| 3xl | 64px | Reserved (page-level breathing room) |

Exceptions:
- Quick-bar interactive height: **56px** minimum tap target for the Trackpad shortcut button (Material minimum 48px touch target satisfied; 56px chosen for a comfortable persistent bar). This is a component height, not a spacing token.
- Hub tile row height: full-width primary tile is deprecated (see Hub Grid); all 8 tiles now use a uniform cell shape at ~1.4:1 aspect ratio (existing `_halfTile` shape), no per-tile height exception.

## Typography

Documents the scale already in use across shipped screens (verified by grep: sizes 12/14/16/28, weights w400/w600). Exactly 4 sizes, exactly 2 weights — within contract limits. Line heights follow the recommended body 1.5 / heading 1.2.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Caption / metadata | 12px | 400 (600 for emphasis) | 1.4 |
| Label / secondary | 14px | 400 | 1.4 |
| Body / tile label / app-bar title | 16px | 600 (titles & tile labels), 400 (body prose) | 1.5 |
| Display (PIN, presenter timer) | 28px | 600 | 1.2 |

**Notes:**
- New Phase 7 surfaces (Keyboard tile label, Settings rows, quick-bar label, UIPI banner) use ONLY these four sizes.
- Tile label = 16/600 `#E6E8EB` (locked, matches existing `_HubTile`).
- Settings row title = 16/400 `#E6E8EB`; row subtitle/hint = 14/400 `#6B7280`.
- UIPI banner text = 14/400 `#E6E8EB`.
- Icon sizes are NOT type but are contract-fixed: tile icon **32px**; app-bar/action/leading icons **24px**; inline banner/hint icon **16px**.

## Color

60/30/10 split. Palette is LOCKED by D-12; hex values are the exact consts already in the codebase. `buildAppTheme()` seeds `ThemeData` with `#4C8DFF`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0E0F12` (`_bg`) | Scaffold background, app-bar background, base canvas |
| Secondary (30%) | `#16181D` (`_surface`) | Tiles, cards, bottom sheets, Settings rows, quick-bar surface, banner fill |
| Hairline (border) | `#2A2D34` (`_hairline`) | 1px tile borders, dividers, banner top border, Settings group separators |
| Text primary | `#E6E8EB` (`_text`) | Titles, tile labels, primary body |
| Text muted | `#6B7280` (`_muted`) | Tile icons, secondary/subtitle text, disabled labels, hint text |
| Accent (10%) | `#4C8DFF` (`_accent`) | See reserved-for list below |
| Destructive / error | `#FF6B6B` (`error`) | Destructive-action affordances and true error copy ONLY |

**Accent reserved for (explicit — accent is NEVER "all interactive elements"):**
- The persistent **Trackpad quick-bar** button (leading icon + label) — its one job is to signal the primary always-available affordance.
- **Active/ON control state**: the haptics `Switch` ON track/thumb, sliders' active track (sensitivity), and the currently-selected value in the scroll-direction control.
- Focus/selection indicators inside the App Settings screen (selected segment, focused text field underline).
- The **display-only accent swatch** in Settings (a static `#4C8DFF` chip labelled "Accent — Blue", non-interactive, no picker).

**Accent is explicitly NOT used for:**
- Hub tiles — tiles are navigation, not state: **InkWell ripple only, no accent flash** (locked, matches existing `_HubTile` contract). This holds for all 8 tiles including the new Keyboard tile.
- The UIPI banner (informational/warning, uses surface + muted, see below).
- App-bar title or the settings gear icon (both `#E6E8EB` / default icon color).

**Destructive (`#FF6B6B`) reserved for:** the "Revoke" affordance on a paired-PC row in App Settings (client-side surface of SRV-03 revoke), and any true error text. NOT used for the UIPI banner (that is a non-error advisory).

## Component & Interaction Contracts (phase-specific)

### 1. Hub dashboard — uniform 2×4 grid (UI-01 / D-08 / D-09)

**LOCKED SHAPE: uniform 2×4 grid.** All 8 tiles are equal size, laid out **2 columns × 4 rows** in the exact D-09 order. This **overrides** the legacy `HubTileGrid` behavior where `tiles.first` rendered full-width. Trackpad is NOT a hero tile — the persistent quick-bar now carries Trackpad primacy (Pitfall 9 resolution).

- **Tile order (exact, top-left → reading order):** Trackpad, Keyboard, Media, Apps, Clipboard, Power, Presenter, Browser.
- **Grid layout:** 2-column rows, `md` (16px) inter-tile gaps, `md` (16px) horizontal edge padding, `xl` (32px) top padding (matches existing `EdgeInsets.fromLTRB(16, 32, 16, 16)`). Each cell keeps the existing `~1.4:1` aspect ratio (`_halfTile` shape) applied uniformly to all 8.
- **Tile visual (unchanged, all 8 uniform):** `#16181D` fill, `#2A2D34` 1px border, 16px corner radius, centered `Column`: icon 32px `#6B7280` + `xs` (4px) gap + label 16/600 `#E6E8EB`. Material `InkWell` ripple only (navigation, not state — **no accent flash**).
- **Tile icons:** Trackpad `Icons.touch_app`, **Keyboard `Icons.keyboard`** (new), Media `Icons.music_note`, Apps `Icons.apps`, Clipboard `Icons.content_paste`, Power `Icons.power_settings_new`, Presenter `Icons.slideshow`, Browser `Icons.public`.
- **App bar:** background `#0E0F12`; title = device name (16/600, fallback "Remote"); trailing = inherited `ConnectionHeaderChip` AND a new **settings gear** (`Icons.settings`, 24px, `#E6E8EB`) at `md` inset (D-11). The gear is always tappable, including offline.
- **Reconnect banner slot** under the app bar stays as-is (`ReconnectingBannerSlot`).

**Implementation note (non-visual):** `HubTileGrid` changes from "first full-width + rest chunked" to "all tiles chunked into 2-column rows"; it still "chunks any list", so this is a small layout change, not a rewrite.

### 2. Offline-disabled tile state (UI-01 / D-08)

When the PC is offline/disconnected, every tool tile is **disabled** except the path to Settings and add/switch-PC.

- **Disabled tile visual:** same `#16181D` fill + `#2A2D34` border, but icon and label rendered in `#6B7280` (muted) at reduced emphasis, `InkWell` `onTap` = null (no ripple, non-tappable). Do NOT hide tiles — they stay visible so the layout is stable; they read as "unavailable right now."
- **Always-reachable while offline:** the app-bar settings gear (→ App Settings) and the add/switch-PC entry. The App Settings screen and the paired-PC list function offline.
- **Offline signal source:** the existing `connectionStatusProvider` / `ChipStatus`; disabled state is driven by connection status, not per-tile logic.
- Tiles never throw on tap while connecting — tool screens already gate their own sends; but the offline disabled state is the primary, clear signal.

### 3. Persistent Trackpad quick-bar (UI-01 / D-10)

A single-button persistent bar giving one-tap access to the full Trackpad from every tool screen.

- **Target file:** `lib/widgets/quick_bar_scaffold.dart` — `QuickBarScaffold({required Widget body, bool showQuickBar = true})`.
- **Visual:** bottom-anchored bar, `#16181D` surface with a top `#2A2D34` 1px hairline, height 56px, full-width. Centered (or leading) button: `Icons.touch_app` + "Trackpad" label, both in `#4C8DFF` accent (this is the reserved accent affordance). Tap = `Navigator.push(TrackpadScreen)`.
- **NOT a live mini-pad** — it is a shortcut button only (the richer peek-pad is deferred).
- **Visibility rule:** visible on every tool screen (Keyboard, Media, Apps, Clipboard, Power, Presenter, Browser) AND could appear on the dashboard. **Hidden / no-op on the Trackpad screen itself** (`showQuickBar: false`, or the wrapper omitted there) — no redundant shortcut to the screen you are on.
- **Placement:** wrap each tool screen's body (or centrally at the `HubScreen._open` push seam). Does not overlap screen content — it reserves its 56px at the bottom.
- **Haptics:** the quick-bar tap fires `hapticTick()` (gated — see below).

### 4. Keyboard tile & screen (UI-01 / D-09)

- **New tile** (position 2, after Trackpad) opens a **new `KeyboardScreen`** (`lib/keyboard/keyboard_screen.dart`) that **reuses the existing modular `KeyboardPanel`** (`keyboard_panel.dart`, `hidden_text_input.dart`, `key_rows.dart`, `modifier_fsm.dart`). Today Keyboard is a panel inside the Trackpad screen; this promotes it to a first-class screen.
- **Screen chrome:** app bar `#0E0F12`, title "Keyboard" (16/600 `#E6E8EB`), body = `KeyboardPanel` on `#0E0F12`, wrapped in `QuickBarScaffold` (quick-bar visible). No new visual language — reuse the panel's existing key/modifier styling.

### 5. App Settings screen (UI-02 / D-11)

Reached via the dashboard app-bar gear (reachable offline). Target: `lib/settings/settings_screen.dart`.

- **Chrome:** app bar `#0E0F12`, title "Settings" (16/600). Body = scrollable `#0E0F12` canvas of grouped rows on `#16181D` surfaces separated by `#2A2D34` hairlines, `md` row padding, `lg` between groups.
- **Groups / rows (order):**
  1. **Paired PCs** — list of paired PC rows (name + `ip · paired` metadata, existing `deviceMetaPaired` style), each with a trailing **"Revoke"** action in `#FF6B6B`; revoke triggers the destructive confirmation (see copywriting) then the SRV-03 revoke path. Also the add/switch-PC entry lives here (the former device-list is the add/switch-PC screen).
  2. **Pointer sensitivity** — reuses the existing `sensitivity.dart` seam (slider, accent active track).
  3. **Scroll direction** — segmented "Natural" / "Reversed" (accent marks the selected value); persists to `shared_preferences`, plumbs into the trackpad driver.
  4. **Haptic feedback** — `Switch`, default ON, accent ON-state; writes `shared_preferences`.
  5. **Accent** — static row: label "Accent" + a non-interactive `#4C8DFF` swatch chip labelled "Blue" (display-only, **no picker**).
- **Offline behavior:** the whole screen and the paired-PC list function while offline.

### 6. Haptics gate (UI-02 / D-13)

- New setting `hapticsEnabledProvider` (`shared_preferences`, default **ON**), with a cached bool read on hot paths (mirror the `sensitivity.dart` cached pattern — never `ref.read` per tap).
- Single helper `hapticTick()` in `lib/settings/haptics.dart`: `if (_hapticsCached) HapticFeedback.lightImpact();`. Call sites (~15: apps, browser, clipboard, media, keyboard panel, trackpad, power [mediumImpact], presenter) route through the helper instead of calling `HapticFeedback.*Impact()` directly. Power's `mediumImpact` keeps its stronger tick via a variant, still gated.
- No visual surface beyond the Settings toggle; this is a behavior contract.

### 7. Keep-awake ref-count (UI-02 / D-14)

- Not a visual surface, but a locked interaction contract: replace bare global `WakelockPlus.enable()/disable()` with a **ref-counted** helper `lib/widgets/keep_awake.dart` (int of active requesters; enable only 0→1, disable only 1→0). Both Trackpad and Presenter route through it.
- **Reason:** the new quick-bar nav path (`Presenter → quick-bar → Trackpad → back`) makes `Trackpad.dispose()` call the global `disable()` while Presenter still wants the screen awake (Pitfall 8). The ref-count prevents that leak. This is the concrete deliverable of the "audit," not "confirmed fine."

### 8. UIPI transient banner (SRV-05 client surface / D-07)

Client surface for the `input.blocked` (proto 1.3) push.

- **Copy:** "Can't control this window — it's running as administrator".
- **Type:** transient, **non-blocking** advisory — NOT a permanent header chip, NOT an error dialog.
- **Visual:** a strip mirroring the existing `ReconnectingBannerSlot` pattern — `#16181D` surface with a `#2A2D34` 1px edge, leading `Icons.info_outline` (or `Icons.shield_outlined`) 16px in `#6B7280`, text 14/400 `#E6E8EB`. **Does not use `#FF6B6B`** (this is advisory, not an error) and does not use accent.
- **Behavior:** slides in on the `input.blocked` frame, **auto-dismisses after ~4s** (a `Timer`), does not intercept touch on the screen beneath it. Contextual — appears on whatever tool screen is active (typically Trackpad) when input is dropped by an elevated foreground window. Debounced server-side to a transition (no per-frame spam).
