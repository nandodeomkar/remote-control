## Phase Goal (slice)

**As the** owner, **I want to** the server to expose a live device count, honor a revoke by dropping the phone immediately, and announce input-blocked events, **so that** the tray tooltip (SRV-01), settings revoke (SRV-03/D-05), and the UIPI banner (SRV-05) all have a real server-side seam. This clones the shipped `vol.changed`/`apps.changed`/`clip.changed` discipline exactly.

<objective>
Add three transport seams to server-core in one plan (they all live in session.rs/mod.rs/listener.rs, so co-locating avoids repeated edits): a `conn_count` watch (SRV-01 tooltip), a `revoke` force-disconnect branch (D-05), and the authed-gated `input.blocked` push branch (SRV-05), plus the SERVER_PROTO_VERSION 1.2→1.3 bump. main.rs is edited here ONLY to supply interim producers for the three new `ServerDeps` fields so the workspace stays green (the 06-01 precedent); real wiring (tray tooltip reader, input-thread blocked sender, settings-driven revoke) lands in 07-06/07-07/07-08.

Purpose: give SRV-01/SRV-03/SRV-05 a single, tested server-core foundation cloning the authed-gated `select!` push pattern the codebase already ships four times.
Output: extended `ServerDeps` + `run_session` params + three `select!`/lifecycle behaviors + proto 1.3 + integration/unit tests.
</objective>
