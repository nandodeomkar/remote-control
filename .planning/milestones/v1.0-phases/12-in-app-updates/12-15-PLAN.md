<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server-supplied strings -> screen | Version strings and error codes originate off-device |
| user tap -> 70 MB download or a PC install | The screen is where consent is expressed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-06 | Information Disclosure | row and footer copy | mitigate | Every failure renders one of seven fixed sentences from the D-11 code map. No error code, HTTP status, exception class, file path, URL or hash is representable in the row state, so none can reach the screen. Asserted by widget tests over the whole matrix |
| T-12-51 | Tampering | accidental install trigger | mitigate | The row body has no recognizer at all - no `InkWell`, no press flash - so a mis-tap cannot start a 70 MB download or a PC install. Asserted by a test that taps the row body and observes nothing |
| T-12-52 | Spoofing | a lying version string on screen | mitigate | Versions render verbatim from the package and the tag with a leading `v` stripped, never reformatted. An unparseable value renders `Version unknown` rather than being coerced into something that looks actionable |
| T-12-01 | Elevation of Privilege | the Update button on the PC row | mitigate | Recorded for continuity: the button sends `update.apply` carrying a version string and nothing else. The server resolves every asset URL and hash itself from a compiled-in repo constant and NEVER accepts, derives, or is influenced by a target supplied over the wire (D-14). No screen affordance can widen that |
| T-12-53 | Elevation of Privilege | the install-unknown-apps grant | mitigate | The explainer sheet states plainly what the grant does and that it can be revoked. The app never polls for the grant and never auto-resumes a download after the user returns from system settings, so the grant cannot be converted into a surprise install |
| T-12-54 | Denial of Service | UI thrash from progress ticks | mitigate | State is value-equal and progress is throttled upstream; row state changes are instant with no animation, so a fast stream cannot queue transitions |
| T-12-SC | Tampering | pub.dev installs | accept | No dependency added; the icon and theme packages are already pinned and guarded by `theme_tokens_guard_test` and `icons_guard_test` |
</threat_model>
