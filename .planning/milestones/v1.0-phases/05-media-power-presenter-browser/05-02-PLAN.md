safely lock/sleep/restart/shut down the PC, drive slide shows, and steer the
browser from my phone, **so that** the everyday control-center extras work
end-to-end without leaving the couch.

_Slice framing:_ After this plan, the user can do two new things: open the hub
from a device row (trackpad still one tap away as the primary tile) and drive
the PC browser (back/forward, tabs, refresh, zoom) — full vertical slice with
ZERO server changes.

Purpose: establish the navigation skeleton every later tool slice plugs a tile
into, and prove the tool-screen pattern (header chip + sendReliable + haptics)
end-to-end.
Output: HubScreen (grid ready for 8 tiles, 2 now), BrowserScreen, rerouted
device list.
