<objective>
Deliver the phase headline change: the dot-grid trackpad texture on BOTH the
full Trackpad surface (24px tiles) and the floating-window surface (22px tiles),
implemented as a purely decorative painter that lives UNDER the raw `Listener`
and never intercepts pointer events. Also close the trackpad-area deltas the
09-UI-SPEC per-screen table names alongside the texture: the floating-window
mouse-button bar drops to 56px (the full-trackpad bar stays 64px), the trackpad
hint text takes its spec color #4a505c, and the excluded prototype effects (fake
cursor dot, tap ripple) are confirmed absent.

Purpose: `trackpad_core.dart` currently renders a flat `color: kBg` surface
(line ~239) with a `kMuted` hint. The approved prototype textures that surface
with a repeating dot grid (lines 99 / 405) and renders the hint in #4a505c
(line 130 for keyboard, same hue for the trackpad hint). Because the full screen
and the floating window mount the SAME shared `TrackpadCore` (08-02), the texture
must be tile-size-parameterized so one widget serves both 24px and 22px surfaces.

Output: a new `dot_grid.dart` painter + hint const, a tile-parameterized
`TrackpadCore`, a 56px window mouse bar, and a widget test proving the dot layer
exists, differs per surface, and stays non-interactive.

ZERO locked-token changes: dots use `Color.fromRGBO(255, 255, 255, 0.045)` and
the hint uses `Color(0xFF4A505C)` — neither is one of the seven `tokens.dart`
consts, so the theme-token guard (which forbids only the seven locked literals)
is not tripped. Do not add, rename, or re-tune any of the seven locked tokens.
</objective>
