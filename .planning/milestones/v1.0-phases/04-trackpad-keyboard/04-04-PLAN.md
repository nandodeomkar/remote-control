|----------|-------------|
| touch input -> authed session -> OS input | Gestures become real clicks/drags/scrolls on the PC through the already-gated session |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Denial of Service (local) | momentum loop / long-press timer | mitigate | Generation-guarded timers cancelled on StopFling, disconnect reset, and dispose — no orphaned frame source; per-tick sends stop below kMomentumStopVelocity |
| T-04-07 | Tampering (stale held state) | drag-lock across disconnect | mitigate | driver.reset() on ChipStatus.disconnected clears client drag-lock/pill; server HeldInput.release_all (CONN-07, shipped) releases the real held button |
| T-04-05 | Spoofing / EoP | pre-auth input | mitigate | All sends ride sendMove/sendScroll (volatile gate) or sendReliable (auth-flushed queue) — gated states also render controls inert (UI-SPEC gated treatment) |
| T-04-SC | Supply Chain | no installs | accept | No new packages; shared_preferences already locked and vetted |
</threat_model>
