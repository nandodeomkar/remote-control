## Phase Goal

**As a** laptop owner, **I want to** use my phone as a precise mouse and full
keyboard for my Windows laptop, **so that** it replaces a real trackpad and
keyboard — not a toy.

_Slice framing:_ The typing vertical slice. After this plan the user can TYPE
anything on the PC through the phone IME — end-to-end against 04-02's real
`type_text`/`backspace` executors. Special-key rows and sticky modifiers follow
in 04-06 inside the panel shell this plan builds.

Purpose: IME-correct typing fidelity — the ROADMAP criterion-2 hard cases
(multi-codepoint emoji, rapid backspace, IME revisions) reproduce the shared
protocol fixtures byte-for-byte.
Output: `ImeDiffProducer` (+ sentinel model), `HiddenTextInput`, `KeyboardPanel`
shell, panel toggle in the trackpad screen.

SENTINEL MODEL: the controller text always starts with `kImeSentinel` (8 × U+200B zero-width space — each ZWSP is its own grapheme cluster, invisible, so the field is never empty and a backspace at the boundary still shrinks the text). `seedText` getter exposes the sentinel for the field's initial value; `needsReseed(String current)` is true when current no longer starts with the full sentinel; `reseed()` returns the fresh seed and resets `_committed` to it (the widget writes it back to the controller WITHOUT emitting).
    - Test (plain insert): committed sentinel, onChanged(sentinel + 'a') → exactly one TextMsg(bs: 0, ins: 'a').
    - Test (IME revision, fixture 02): sentinel+'thw' → sentinel+'the ' emits TextMsg(bs: 3, ins: 'the ') — matches the ime-revision fixture semantics.
    - Test (emoji, fixture 03): appending '👋🏽' emits TextMsg(bs: 0, ins: '👋🏽') as ONE insert; a following backspace emits TextMsg(bs: 1, ins: '') — one grapheme, not code units.
    - Test (boundary backspace + reseed): committed == sentinel, onChanged(sentinel minus one ZWSP) → TextMsg(bs: 1, ins: '') AND needsReseed is true; after reseed() the committed text equals the full sentinel and no message was emitted by reseed itself.
    - Test (no-op): onChanged with unchanged text emits nothing.
    - Test (rapid backspace, fixture 04): three successive single-grapheme shrinks emit three TextMsg(bs: 1, ins: '') — never a coalesced wrong count.
