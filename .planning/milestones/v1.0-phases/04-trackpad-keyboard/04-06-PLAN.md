## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Denial of Service (local) | locked modifiers / held key caps | mitigate | D-12 client reset on disconnect + CONN-07 HeldInput.release_all (shipped) + enigo release_keys_when_dropped backstop — no stuck Ctrl/Win after a drop |
| T-04-02 | Tampering / Input Validation | emitted key codes | mitigate | kClientKeyCodes mirrors keymap.rs CLIENT_KEY_CODES (coverage-tested both sides); unknown codes are dropped silently server-side (ASVS V5, 04-02) |
| T-04-05 | Spoofing / EoP | pre-auth key frames | mitigate | All KeyMsg traffic rides sendReliable behind the auth-gated SendPolicy; gated UI renders chips/caps inert (UI-SPEC disabled states) |
| T-04-SC | Supply Chain | no installs | accept | No new packages this plan |

Note: combos like Ctrl+Alt+Del are user-invoked keystrokes on the user's own authed session — deliberately NOT confirmation-gated (UI-SPEC Copywriting: a confirmation would defeat a keyboard; double-confirmed power actions are Phase 5).
</threat_model>
