<objective>
Switch the server's pointer injection from RELATIVE to ABSOLUTE so slow/small
drags bypass the Windows "Enhance pointer precision" ballistics curve and track
1:1 (D-01), while keeping the existing sub-pixel accumulator (D-02) and correctly
normalizing to the multi-monitor VIRTUAL desktop (D-03). Confirmed problem from
the Phase-2 gate (02-04-GATE-RESULT.md pointer-accel finding, folded todo
2026-07-08-absolute-pointer-injection).

## Phase Goal

**As a** laptop owner, **I want to** use my phone as a precise mouse and full
keyboard for my Windows laptop, **so that** it replaces a real trackpad and
keyboard — not a toy.

_Slice framing:_ This plan makes the ALREADY-shipping move path (Phase 2/3)
deliver true 1:1 fidelity — the first user-visible improvement of the phase, and
the OS-injection foundation both later client slices need on device (RESEARCH
recommends server executors land first — neither client slice is on-device
testable without real injection).

Purpose: Retire the ballistics-suppression bug and the multi-monitor edge case
permanently, using the already-present `windows` crate (no new packages).
Output: A `normalize_virtual` pure fn (unit-tested without a display), the two
Win32 feature flags, and an absolute-inject `Cmd::Move` arm.
</objective>
