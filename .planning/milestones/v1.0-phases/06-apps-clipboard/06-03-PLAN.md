## Phase Goal

**As a** person controlling my PC from my phone, **I want to** see and manage my open windows and apps and move copied text between the two devices, **so that** I can switch apps, launch favorites, and share clipboard text without touching the laptop.

<objective>
Ship the Apps screen — the user-facing half of the Apps slice. Consumes the 06-01 contract (WindowInfo icon/path, err arms, apps.changed) and, against a real server (06-02), lets the owner see their windows live, focus/close them, pin favorites from running windows, and relaunch pinned apps.

Purpose: Completes APPS-01/02/03 end-to-end on the phone. This is the "a real user can now do something" slice of the Apps track.

Output: Dart `WindowInfo` icon/path mirror + fixture test; `ConnectionService` AppsSnapshot + err arms; `AppsNotifier` + favorites `PrefsKv` store; `AppsScreen` (favorites grid + open-windows list) per 06-UI-SPEC; the Apps hub tile.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Apps screen → apps.launch | The client must only ever send back a path the SERVER produced |
| favorites store (local) | Non-secret prefs; must never hold or send user-typed paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04 | Tampering | `apps.launch{path}` from the client | mitigate | Favorites are pinned ONLY from a running window's server-resolved `WindowInfo.path` (D-01); there is no manual-path entry field anywhere in the UI (D-01 forbids it). The launch path is always a value the server enumerated and sent — the client cannot originate an arbitrary path |
| T-06-14 | Information disclosure | err toasts / logs | mitigate | Toast copy uses the UI-SPEC operator-facing strings; HWND ids and exe paths are never shown to the user nor logged (copy contract, SPEC §12) |
| T-06-15 | Tampering | favorites persistence | mitigate | Stored in `shared_preferences` (non-secret) via PrefsKv, never SecureKv (house rule); corruption-tolerant load degrades to empty, never throws |
| T-06-SC | Tampering | crate/package installs | accept | This plan adds no new packages (Clipboard/flutter built-ins + existing riverpod/shared_preferences); no legitimacy checkpoint required |
</threat_model>
