## Phase Goal

**As a** person controlling my PC from my phone, **I want to** see and manage my open windows and apps and move copied text between the two devices, **so that** I can switch apps, launch favorites, and share clipboard text without touching the laptop.

<objective>
Ship the manual Clipboard slice: the Clipboard screen with one-tap Send to PC, Fetch from PC, and a persistent last-5 history whose entries re-push to the PC. Consumes the 06-04 server clipboard (clip.set/clip.get/clip.changed) and the 06-03 connection-service wiring.

Purpose: Completes CLIP-01, CLIP-02, CLIP-04 end-to-end on the phone — the send/fetch/history capabilities a user can immediately use. Auto-sync (CLIP-03) layers on in 06-06.

Output: `ConnectionService` ClipSnapshot + fetch-reply arms; `ClipNotifier` + history `PrefsKv` store; `ClipboardScreen` (Send/Fetch + history) per 06-UI-SPEC; the Clipboard hub tile.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone clipboard → clip.set | User-initiated; text the user explicitly Sends |
| history store (local) | Non-secret prefs; must never hold sensitive-skipped clips |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-09 | Information disclosure | clipboard text in logs | mitigate | Neither the ClipSnapshot/fetch-reply arms nor the store log clipboard text (SPEC §12); snackbars show fixed copy strings, never the text payload beyond the intended history preview |
| T-06-17 | Information disclosure | history persistence | mitigate | History goes to `shared_preferences` (non-secret) via PrefsKv, never SecureKv (house rule). Sensitive PC clips are skipped server-side (06-04) so they never arrive to be recorded; Send/Fetch only record text the user explicitly moved |
| T-06-16b | DoS | oversized Send | mitigate | `send()` refuses text over the ~48 KiB hard cap (client pre-send check) so no clip.set frame nears the 64 KB tungstenite cap |
| T-06-SC | Tampering | package installs | accept | No new packages — Clipboard is a flutter/services built-in; existing riverpod/shared_preferences reused. No legitimacy checkpoint required |
</threat_model>
